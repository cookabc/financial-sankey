Guide

  1. Prepare three columns

    Arrange as source, target, amount. CSV, TSV, XLSX and Excel paste all work, with or without a header row. XLSX can pick a sheet. A single table holds up to 200 flows and 80 nodes.

  2. Generate and check

    The chart uses only the numbers you provide. When a middle node’s inflow and outflow disagree it says so plainly and never fills the gap. Duplicate flows are summed; zero amounts are not drawn.

  3. Small flows and line width

    The default minimum width is 4 canvas pixels. Small flows are drawn wider than strictly proportional while their amount stays true; visible ribbon width and node height adjust together so ports stay filled, and neither the amount nor the balance check changes. Turn it off in “Customise chart style” for strict proportions. Hover or tap a ribbon to read its real amount.

  4. Export in your own style

    Set the title, period, unit and palette, and click a node to reorder its column. PNG suits slide decks; SVG keeps vector sharpness. A JSON project can be opened and edited again.

The three-column table takes non-negative flows and no cycles; a structured statement supports explicit additions and a loss accounting bridge. Data format · JS / CLI docs PDFs and free-form prose are not parsed. All import, calculation and export happen locally in the browser.
