使用指南

  1. 准备三列数据

    按「来源、去向、金额」排列。支持 CSV、TSV、XLSX 和 Excel 复制粘贴，含表头或不含表头均可。XLSX 可以选择工作表。单表最多 200 条流向、80 个节点。

  2. 生成并核对

    图表只使用你提供的数值。中间节点流入与流出不一致时会明确提示，不会自动补齐。重复流向会合并求和，零金额不会绘制。

  3. 小额流线与线宽

    默认最小线宽为 4 画布像素。小额流线会增强显示，金额为真实值，宽度非严格同比例；显示流宽与节点高度会共同调整、保持端口铺满，不改变金额或收支校验。可在“自定义图表样式”中关闭以使用严格比例。悬停或点击流线可查看真实金额。

  4. 按你的风格导出

    设置标题、期间、单位和配色，点击节点调整同列顺序。PNG 适合演示文稿，SVG 保留矢量清晰度。JSON 项目可以再次打开编辑。

三列表使用非负流值，不支持循环；结构化财报支持显式加减项与亏损会计桥。支持 JSON 结构化财报。数据规范 · JS / CLI 文档。不识别 PDF 或散乱自然语言。所有导入、计算和导出均在浏览器本地完成。
